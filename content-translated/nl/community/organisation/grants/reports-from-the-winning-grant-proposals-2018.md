{{<content-start >}}

<p>Met het <a href="http://blog.qgis.org/2018/06/22/qgis-grant-programme-2018-results/">QGIS Grant Programme 2018</a> waren we in staat zeven aanvragen te ondersteunen die erop waren gericht om het project QGIS te verbeteren, inclusief software, infrastructuur en documentatie. Hier zijn de rapporten over het werk dat binnen de individuele projecten werd uitgevoerd:</p>
<ol>
<li><strong><strong>Verhoogde stabiliteit voor gebruikersinterface van Processing en externe providers (Nyall Dawson)<br />
</strong></strong>Veel problemen van 3e-partijproviders zijn opgelost en heel veel nieuwe eenheidstesten toegevoegd. De gebruikersinterface bevat nieuwe klassen van C++ en een  nieuw framework dat is geland in QGIS 3.4. Bekijk voor meer details Nyall&#8217;s <a href="https://lists.osgeo.org/pipermail/qgis-psc/2018-September/006601.html" rel="nofollow">rapport op de mailinglijst</a>.</li>
<li><strong>OSGeo4W updates (Jürgen Fischer)<br />
</strong>De updates die in dit project werden uitgevoerd zijn essentieel om QGIS 3.x naar Windows te kunnen brengen.</li>
<li><strong>Herstellen Processing &#8220;R&#8221;-provider (Nyall Dawson)</strong><br />
De provider R is geïmplementeerd als een providerplug-in. De <a href="https://lists.osgeo.org/pipermail/qgis-developer/2018-November/055329.html" rel="nofollow">bètafase werd al in november 2018 aangekondigd</a> voor de plugin  en de <a href="https://north-road.github.io/qgis-processing-r/" rel="nofollow"></a> voor algemeen gebruik.</li>
<li><strong><a href="https://github.com/qgis/QGIS-Enhancement-Proposals/issues/121">Ondersteuning van OpenCL voor bronalgoritmes van Processing</a> (Alessandro Pasotti)</strong><br />
De volgende algoritmes van Processing zijn geporteerd: helling, aspect, schaduw voor heuvels en ruwheid. Zelfs hoewel dat niet in het bereik van deze QEP lag, is de renderer voor schaduw van heuvels ook geoptimaliseerd. Bekijk voor meer details <a class="issue-link js-issue-link" href="https://github.com/qgis/QGIS/pull/7451">qgis/QGIS#7451</a>.</li>
<li><strong>QGIS server OGC-compliant en gecertificeerd voor WFS (Régis Haubourg) </strong><br />
Dit project repareerde heel veel problemen om dichter bij het doel te komen om QGIS Server gecertificeerd te krijgen voor WFS. Het project had echter onvoldoende fondsen om het doel te bereiken. Bekijk voor de details <a href="http://test.qgis.org/ogc_cite/wfs_110/latest/report.html" rel="nofollow">de huidige WFS testen statuspage</a>.</li>
<li><a href="https://gist.github.com/m-kuhn/e530f6e838dbbf608f12f2da39f8a18d#file-charts-and-drawings-attribute-form-md"><strong>Diagrammen en tekenen op attribuutformulieren</strong></a><strong> (Matthias Kuhn)<br />
</strong>Lees voor de details <a href="https://www.opengis.ch/2018/11/06/qml-widgets-qgis/" rel="nofollow">&#8220;The new QML widgets in QGIS&#8221;</a> en bekijk <a class="issue-link js-issue-link" href="https://github.com/qgis/QGIS/pull/7801" aria-label="qgis/QGIS#7801, [FEATURE] QML chart and drawings widget">qgis/QGIS#7801</a>.</li>
<li><strong>Update van QGIS Trainingshandleiding (Matteo Ghetta)</strong><br />
Dit project is nog niet voltooid.</li>
</ol>
<p>Dank aan iedereen die heeft deelgenomen en deze ronde van grants een groot succes maakte, en dank aan al onze sponsoren en donoren die dit initiatief mogelijk maakten!</p>
