# QGISを使用したトレーニング＆研究活動 、NIRD&PR-NERC, グワハティ、インド
<p class="is-size-6 is-italic has-text-weight-medium">
  <span class="icon">
    <i class="fas fa-calendar-alt"></i>
  </span>
  <span>July 01, 2014</span>
</p>

農村開発＆パンチャーヤット（NIRD＆PR）国立研究所は、インド政府農村開発省の研修機関です。本部はインドのハイデラバード市に位置しており、三つのサブセンターがグワハティ、ジャイプールとパトナ市にあります。グワハティは、アッサム州（国の北東側）の首都です。NIRDグワハティセンターは、8つの北東インド州の州、地区、ブロックレベルの政府関係者のための短期（1日の携帯GPS測量を含めほとんどが5日）の住宅GISトレーニングに積極的に関与しています。政府関係者とは別に、大学の教職員、大学の講師、研究の学者、いわゆるNGOも訓練しています。トレーニングは完全にNIRDにより主催されており、参加者は旅費だけ負担することになっています。著者はNIRDグワハティセンターで非常勤講師（GIS）として勤務しており、当センターにおいて GIS と農村開発に関連する訓練を K. Haloi 博士（訓練＆研究コーディネーター、I / Cヘッド、C-GARD、NIRD&PR-NERC）と一緒にコーディネイトしています。

当初、私は ArcGIS や ERDAS といった商用ソフトウェアを用いた GIS トレーニングの実施に携わっていました。しかし、参加者は研修プログラム終了時に実習用のソフトウェアを入手できなかったため、不満を抱いていました。そこで、QGIS を導入することで解決策を見出しました。QuantumGIS を導入した後、このオープンソース GIS がインドの農村開発分野のニーズを満たせるという認識が広まりました。これに伴い、道路、排水路、集落、流域境界の画定などの基盤地図の作成や、GPSデータのダウンロード・分析、GPS調査の現場写真とのハイパーリンク設定などの研究活動に導入されました。また、Google Earthプラグインを活用して、LULC 地図の作成にも取り組んでいます。

その後、1年間にわたり個人利用としてこのソフトウェアを活用し、新バージョンでは機能が強化されているかを確認しました。この間、筆者が研修のコースコーディネーターを務めていた際には、トレーニングにおいてQGISを導入説明やフィードバックに活用しました。

当センターでは、GISトレーニングにQGISが活用されています。さらに、すべての研修において、真に必要性を感じない限り、地区（インドにおける国・州に次ぐ行政単位）およびそれ以下のレベルでは商用GISソフトウェアを購入すべきではないこと、そしてその節約分をGPSやコンピュータなどのハードウェアの購入に充てるべきであることが、繰り返し伝えられ、推奨されています。トレーニングでは、参加者にジオリファレンス、データベースの作成、デジタイズ、編集、分析、プリントコンポーザーなどの操作を紹介してきました。QGIS の導入後、さまざまな職員や学生から好評をいただいています。

uDig、MapWindow、gvSIG、GRASS といった他のソフトウェアもあるのに、なぜ QGIS だけなのかという疑問があります。その答えは、QGISがOSGeoのインキュベーションプロジェクトであり、複雑さが比較的低く、開発のスピードが非常に速く、膨大なユーザーおよび開発者コミュニティに支えられていること、そして最後に、開発者たちの専門知識にあります。最新バージョンである2.4により、このソフトウェアは、インドの草の根レベルの農村開発実施者たちのあらゆるニーズを満たすとともに、現在の要望や将来への期待にも応えることができます。

トレーニングにおけるソフトウェアの適用は、一般的に、資源図化、農村インフラ施設の図化、流域とマハトマ・ガンジー国立農村雇用保証制度（MGNREGS）に集中しています。流域とMGNREGSは、インド政府の土地ベースの最高に重要なものです。地域のオープンソースなラスターとベクターデータが演習で使用されています。参加者は、作業に利用可能な場合、独自または部署のデータを持参することが奨励されています。トレーニングは、i7、4 GB RAM と Windows8 OS を搭載した22台のコンピューターのある実験室で提供されています。訓練生のトレーニングあたりのプログラム数は20-30の間です。

## 行われたQGISトレーニングコースと参加者
カバーされる一般的なトピックは、GIS と QGIS ソフトウェアの基本的な紹介、主要なツールバー、プラグイン構造、ジオリファレンス、ベクターデータの作成/編集、クリッピング（ラスター/ベクター）、マージ、地形分析、等高線、.CSVから.SHPレイヤー、.SHPから.KMLおよびその逆、GPSデータの取り扱い、補間、テーブル編集/クエリ、フィールドの計算、印刷コンポーザなど、そしてベクターデータのいくつか基本的な分析。利用可能なさまざまなヘルプリンクの紹介とは別に、訓練後の支援のために参加者の LinkedInのグループは作成されています。QGIS を使った訓練プログラムとは別に、QGISは研究で使用されており、それには地図のジオリファレンス、データベースの作成、toposheetsとグーグルアースからのベクターデータの抽出、編集と分析、GPSデータのダウンロードと処理し、それに　レイアウト調製などがあります。
## 成功
毎月訓練は20-30の参加者で行われているので、この数は毎月増加しています。トレーニングフィードバックは非常に肯定的と励みに残っています。修了証は、トレーニング終了後に参加者に提供されています。現在配布資料はハードコピー、チュートリアル、ソフトウェアおよび練習データはソフトコピーで参加者に提供されていますが、画面を記録した講義/さまざまなトピックのデモを含んだ英語によるDVDを作成する計画があります。将来的には認定証や修了証の学位プログラムも始まる可能性があります。
